2 replay same users across HF/RP/Search with frozen feature snapshot surface diff
3 swap index only; keep cache + feats fixed idx contribution est

Detect

watch topK overlap, p95 age, shard idx age. medians not enough.

Replay

use replay cohort + frozen feature snapshot. same user snap across surfaces.

Isolate

swap index only, then bypass cache, then check feature snapshot completeness.

Mitigate

pause rollout, rebuild lagging shards, tighten embedding freshness gate if evidence holds.
